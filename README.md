# ProfNote EPS (prototype v0.1)
Carnet de suivi des séances d'EPS intégré à Mes Apps EPS (identifiant d'application : `profnoteeps`).
- Une classe = un classeur ; un onglet par cycle + un onglet Bilan automatique.
- Une séance = un groupe de colonnes daté (appel, tenue, infirmerie, dispense, comportement, équipe, temps, distance, nombre/note, calcul, texte).
- Enregistrement dans Mes Apps EPS en mode « lignes » (une ligne par élève et par séance : Date, Cycle, Séance, Appel, Tenue, Infirmerie, Dispense, Comportement, Équipe, Mesures, Observations).
Dépôt prévu : `VinzToc/ProfNote_EPS`, publié sur https://vinztoc.github.io/ProfNote_EPS/ (GitHub Pages). Ajouter la ligne de `apps.json-ligne.txt` dans `apps.json` du portail.
